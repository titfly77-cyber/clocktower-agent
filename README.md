# 血染钟楼 Agent

面向说书人（DM）的流程、氛围与复盘助手。

当前交付为 v0.1 产品规格、事件协议和虚构示例数据，尚未实现 App、音频接入或模型推理。

## 已确认的产品范围

- 首个支持的桌游：血染钟楼。
- 输入：一条包含玩家和 DM 的现场混合音频，以及 App 按键事件。
- App 核心操作：切换阶段、调整氛围。
- 采用 8 个流程状态和 8 种现场氛围。
- 语音提供阶段建议，DM 按键确认实际阶段。
- 阶段总结默认展示给 DM；对玩家展示须由 DM 确认。
- 文件保存在 `E:\BOARD\clocktower-agent`。

“调整氛围”暂按手动纠正现场氛围标签设计；是否需要控制灯光、音乐尚未确认，本版未定义硬件输出协议。

## 文件

- [产品规格](docs/product-spec.md)：阶段、氛围、按钮行为、总结范围与验收场景。
- [事件协议](docs/event-contract.md)：App 与 Agent 之间的事件、状态优先级和修正方式。
- [虚构事件示例](examples/session-events.json)：包含手动切换、过期建议、氛围锁定与恢复自动的示例。

示例中的预期状态用于说明协议，不代表已经运行了 Agent。

## 后续开发前需要补齐的信息

1. App 的目标平台与已有代码情况。
2. 音频接入方式、格式、是否实时传输，以及如何与按键时间对齐。
3. 模型运行位置、可接受的延迟与成本范围。
4. “调整氛围”是否同时涉及灯光、音乐及相应硬件能力。

上述信息不影响本版产品规则定稿，但会影响具体实现。

## 工作目录约定

代码、下载、构建、测试输出和任务控制的缓存均保存在本项目内。后续可能生成临时文件或缓存的命令应将 `TEMP`、`TMP`、`TMPDIR` 指向项目内的 `tmp`，并将工具缓存指向项目内的 `cache`。
